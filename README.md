# 💫 About Me:
Hi, I'm Mayank Joshi — a third-year BTECH  Data Science student at Maharishi University Noida (CGPA: 8.7/10), passionate about building end-to-end machine learning systems that solve real-world problems. I've worked on projects ranging from a fraud detection pipeline (94% ROC-AUC on 284K+ records) to a CRAG-based document Q&A system with semantic retrieval and LLM streaming, and a CNN-based plant disease classifier with 96%+ accuracy. My core stack includes Python, Scikit-learn, TensorFlow, LangChain, and the MERN stack, with hands-on experience in EDA, feature engineering, deep learning, and generative AI. I'm a Smart India Hackathon 2024 participant and hold certifications from IIT Roorkee in AI/ML.
